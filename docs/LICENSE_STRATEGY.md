# License and redistribution strategy (pending owner's decision)

No license is selected for this new public repository. Do not assume permission to redistribute its contents or source assets.

- Keep Blender and MPFB as user-installed tools initially. Any future bundling requires an explicit license and distribution review.
- Track the exact installed MPFB source/version, its code license and asset terms independently.
- Fab assets may have different licenses; do not assume cross-engine export, source redistribution or AI model use is permitted for every pack. Honor UE-only and NoAI limits where applicable.
- Do not commit AI weights or the user's bought animation sources. Keep source provenance in a private manifest.
- Only process via cloud when the user has deliberately selected a provider and uploaded content.
- The final app license, third-party notices, commercial asset output permissions and installer policies require documented owner decisions before public distribution.

See `Development_Guardrails/docs/ASSET_POLICY.md`. This is an engineering compliance checklist, not legal advice.
