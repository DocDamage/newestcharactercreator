# UCC-P1-ANIM-006Q — independently reproduced central-body contact review

## Scope

The original/fitted comparison previously measured only hand/opposite-arm
surface crossings. This slice adds a separate read-only inspection of each
hand against actual deforming head, neck, spine and pelvis ancestry. It uses
the complete rig hierarchy and actual evaluated deform weights rather than
mesh names, guessed axes or hard-coded vertex indices.

`HAND_CENTRAL_BODY_TRIANGLES_V1` is a surface-crossing observation policy.
It does not evaluate solid containment, penetration depth, contact intent,
clothing, props, feet or arbitrary body pairs. It never approves grasp,
visual animation quality or engine compatibility.

## Working implementation

- Four closed worker operations cover original-only and original/fitted
  measurement plus independent reproduction. Exact input sets contain six,
  seven, nine or ten SHA-256 values. Fixed staged filenames and private copies
  preserve original source, master, Action and project data.
- Every source frame reopens through the existing raw/corrected skin, rest,
  helper, hip, neutral-reference and source-FK checks. Paired review also
  reproduces the complete canonical fitted report. Two distinct Blender jobs
  must agree on the entire body report before annotations can be returned.
- Actual triangle indices and per-frame skin/topology hashes bind the new
  annotations to immutable playback buffers. The Python application independently
  validates anatomy, complete coverage, timing, region ancestry, world transform,
  pair counts, highlight bounds, private worker receipts and unchanged inputs.
- Compact hand-triangle BVH queries bound transient overlap allocation. Explicit
  work, pair and highlight caps produce **unavailable**, clearing partial
  observations instead of reporting unchecked frames as zero crossings.
- **Review hand/body contacts** runs the guarded local API and supports existing
  cancellation. The viewer switches opposite-arm/body annotations at the same
  frame, camera and clock; original/fitted switching remains available. Navigation,
  highlighting and focus use the selected inspection. Unavailable results cannot
  enable clearance controls or claim zero crossings.
- Bound file changes invalidate playback. Parent-directory events recheck file
  identity and SHA rather than clearing on unrelated diagnostic job creation.
  File events, deleted inputs and atomic replacement still clear both views.
  A newly published body report and all bound evidence join those watches.

isolated body-contact suite while retaining both complete prior suites and
their assertions. It generates its own original source and real MPFB human,
executes original-only review, rejects independently rehashed false body

not proof of owned-pack compatibility.
