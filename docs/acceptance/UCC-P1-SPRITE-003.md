## Current implemented behavior

`UCC_PRIVATE_FACIAL_SPRITES_V1` is separate from the accepted neutral contract.
It binds the saved expression strengths and full 25-frame clip to the project,
master, expression library, material and compatible hand. All per-use permissions
start unchecked; NoAI/source restrictions remain. Zero-strength clips reject as
non-animated. Four/eight directions, 128/256 pixels and explicit yaw/pitch reuse
the accepted camera controls. Each direction receives a 5×5 atlas with 25 samples
at 24 fps, including both neutral endpoints (timestamps 0 through 1 second).

The worker creates the existing pinned shape-key Action on a temporary render
scene. Every frame measures full geometry, exact skin triangles and evaluated
corner normals. A fresh worker renders independent float32 source interpolation
and then the saved Action without repairs; every pixel and measured hash must
match. The host verifies every PNG, transparent margin, endpoint and atlas crop,
then exclusively publishes a new folder. Complete worker hashes and four fresh
job IDs accompany the receipt. No editable Blender scene or target data is
included in the delivered folder. CPU Cycles remains bounded to two threads;
this is not GPU/VRAM or artist/pixel-art acceptance.
