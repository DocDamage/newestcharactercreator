## Reproduce the product flow

Open a saved project. In Animation library, index a selected FBX with its actual
reviewed local-preview rights, then select its measured catalog row. Choose
View > Preview selected source skeleton, confirm the local operation, and select
the installed Blender executable when prompted. The current project holds its
private job files. Play/pause, source seek and Go to source start affect only this
read-only skeleton view. Closing or invalidation releases playback authority;
reopening requires another fresh source check.
