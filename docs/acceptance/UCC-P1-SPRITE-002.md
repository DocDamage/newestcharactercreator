through Blender to transparent RGBA PNGs in four/eight orthographic directions.

Touched files: versioned render contract, isolated Blender staging/reopen worker,
host coordinator/evidence, normal desktop review/action, tests and schemas.
Reversibility: immutable original master/project/history; new private staged scene
and PNGs; publish only a new destination after verification and hash checks.

Acceptance: closed/malformed/stale/rights tests; real Blender source-preservation,
camera/material/scene setup and saved-scene re-render comparisons; decoded alpha,
unclipped nonblank renders and exact atlas pixels; normal desktop controls and

## Implementation and limits

`UCC_PRIVATE_NEUTRAL_SPRITES_V1` binds the saved project revision, master,
expression library, owned material and registered hand to four separately
reviewed permissions. All start unchecked. NoAI remains enabled; UE-only,
source redistribution, animation and public/visual approval remain disallowed.
The File action requires a new destination, explicit authorization text and an
installed Blender executable. No scan, model, network request or installation
was added.

The coordinator freshly checks the saved source/hand/material, stages a private
scene with the original human and rig, and renders deterministic CPU Cycles
32-sample RGBA PNGs. A separate worker reconstructs and renders every direction
from the original source, then opens and renders the saved scene without repair.
Both decoded pixel sets must match the stage. The original editable state and
shader must also match. Exact atlas crops, transparent margins, distinct views,
file hashes and the complete worker dependency set are checked before exclusive
folder publication. Cancellation, a bounded total deadline and own-inode-only
rollback preserve originals. Only images and proof/recipe metadata are delivered;
the temporary editable scene is retained privately in job evidence.
