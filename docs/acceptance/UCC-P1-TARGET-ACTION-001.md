# UCC-P1-TARGET-ACTION-001 — registered private target action

Status: implementation and focused checks in progress. Actual new production
action preparation, saved reload, normal desktop and frozen-app acceptance remain
open. This record does not establish a usable or shipping animation clip.

The workflow uses an explicitly selected, attached source reference and the
current saved neutral humanoid. It prepares a fresh private target Action,
reopens it, verifies the complete playback cache and retains the original
producer requests/results. Saved previews require explicit binding selection
and current source, catalog policy, project and proof validation.

The initial profile is `UCC_MPFB_REGISTERED_TARGET_PREVIEW_V1`: original source
frames 2–301 map to target frames 1–300 at 30 FPS. Playback runs once and holds
the last frame. The existing bound corrective skin policy and numerical gates
remain authoritative. Arbitrary rigs, regional skin V2, loop quality and engine
animation exports require separate acceptance.

The pure contract binds the source reference, selected catalog rows, mapping,
saved project/master, neutral state/rest, selected Blender/resources and nine
actual worker identities. Forty-five retained proof files accompany a canonical
binding document in `animations/actions/<binding-sha256>/`. Original source FBX
and the editable master are not copied into that retained folder. All actual
poses, meshes, saved scenes and rendered proof images remain private.

The save commits at atomic no-replace publication of the fully validated
46-file folder. Before that point, failure publishes no new binding. After that
point, cancellation or a failed current-context preview load retains the saved
historical record and reports its path. Reopening always revalidates eligibility;
retention does not grant permission to play a stale or disallowed source.

Local preview is the only permission admitted here. Source-only reference flags,
editing authorization, project animation records and catalog rights remain
unchanged. Engine use, redistribution, AI, cloud transmission, human motion
approval and usable-clip counts are not established.
